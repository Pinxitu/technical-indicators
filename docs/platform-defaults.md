# Platform defaults

How this library's defaults (see [`docs/formulas.md`](./formulas.md)) compare to the default settings
documented by TradingView, MetaTrader 5, and StockCharts. Every cell is either a value quoted from the
platform's own documentation (URL given) or the literal string **not documented**, meaning that
platform's public docs do not state a numeric default for that parameter — this is never a guess at
what the platform's UI actually ships with.

## Notes

- No platform's documentation states every parameter this library exposes; where a cell says "not
  documented," that reflects the absence of a stated default on that platform's own public help page,
  not an assumption about what ships in the platform's UI.
- Fibonacci retracement levels differ the most across platforms — the 0%/100% extremes are universal,
  but which intermediate ratios a platform enables by default (and whether it also draws extensions
  beyond 100%, as MetaTrader 5 does) varies. This library's default set (`0, 0.236, 0.382, 0.5, 0.618,
  0.786, 1`) matches none of the three platforms exactly; callers who need to match a specific platform
  should pass an explicit `levels` array.
- ADX's default of 14 is documented on TradingView under the combined Directional Movement (DMI)
  indicator rather than a page named "ADX" — TradingView's dedicated ADX help page does not repeat the
  Inputs section.
